# DaoTrine

DaoTrine is a Distributed Data-Driven Engine for Real-time Processing Auto-Scaling of Complex Data Pipelines on a Scalable Platform.

- DaoTrine is a Distributed Data-Driven

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoTrine.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DaoTrine, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
